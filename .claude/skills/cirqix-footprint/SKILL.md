# Cirqix — Agent Footprint

## Cascade (`packages/agents/src/engines/footprint-service.ts::findFootprint`, arrêt à la première réussite)

1. Bibliothèque KiCad standard (locale, instantanée)
1.5. Cache communautaire pgvector (`footprint-cache.ts`)
2. SnapMagic (si `SNAPMAGIC_API_KEY`)
3. LCSC / EasyEDA (HTTP public)
4. Génération du `.kicad_mod` par Haiku 4.5 (3 crédits)

Repli final : empreinte générique (celle du package fourni, sinon `Resistor_SMD:R_0402`).

## Génération .kicad_mod

```typescript
// packages/agents/src/tools/generator.ts
export function generateKicadMod(partNumber: string, dims: PackageDims): string {
  const { pitch_mm, pad_width_mm, pad_height_mm, n_pads, courtyard_margin_mm } = dims;

  return `(footprint "${partNumber}"
  (layer "F.Cu")
  (descr "AI Generated by Cirqix")
  (tags "cirqix ai-generated")
  ${generatePads(n_pads, pitch_mm, pad_width_mm, pad_height_mm)}
  (fp_rect
    (start ${-(pitch_mm * n_pads / 4 + courtyard_margin_mm)} ${-(pad_height_mm / 2 + courtyard_margin_mm)})
    (end   ${ (pitch_mm * n_pads / 4 + courtyard_margin_mm)  } ${ (pad_height_mm / 2 + courtyard_margin_mm)})
    (layer "F.Courtyard") (width 0.05))
)`;
}
```

## Supabase — table footprints

```sql
create table footprints (
  id uuid primary key default gen_random_uuid(),
  user_id uuid references auth.users,
  is_community bool default false,
  name text not null,
  part_number text,
  source text check (source in ('kicad_official','snapmagic','octopart','ai_generated')),
  kicad_mod text not null,
  embedding vector(1536),         -- pgvector pour recherche sémantique
  validated bool default false,
  created_at timestamptz default now()
);

-- Index pour recherche sémantique
create index on footprints using ivfflat (embedding vector_cosine_ops) with (lists = 100);
```

## Cache pgvector

Embeddings : API embeddings OpenAI, 1536 dimensions (`packages/agents/src/engines/footprint-cache.ts`). RPC : `search_footprint_by_part_number`, `search_footprint_by_embedding`, `upsert_community_footprint` (migrations 005 et 011). Sources admises : kicad_official, snapmagic, octopart, lcsc, ai_generated.
